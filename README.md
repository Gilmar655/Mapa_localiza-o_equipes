## Publicação no GitHub Pages

1. Extraia o conteúdo do arquivo ZIP.
2. Envie todos os arquivos desta pasta para a raiz do repositório `Mapa_localiza-o_equipes`.
3. Confirme que o GitHub Pages está configurado para publicar a branch principal pela pasta raiz.

O arquivo principal é `index.html`. Os filtros, gráficos e a tabela funcionam sem bibliotecas externas.
